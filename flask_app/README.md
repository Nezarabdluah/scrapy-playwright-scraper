## 📖 دليل الاستخدام

### 1. إنشاء مشروع جديد
- اضغط **"➕ مشروع جديد"**
- أدخل اسم المشروع
- أدخل الرابط المستهدف
- حدد الحقول المطلوبة (مثال: العنوان, السعر, الرابط)
- اضغط **"إنشاء المشروع"**

### 2. تشغيل المشروع
- اذهب لصفحة **"📁 المشاريع"**
- اضغط **"▶️ تشغيل"** بجانب المشروع
- انتظر الاكتمال!

### 3. تحميل النتائج
- بعد الاكتمال، اضغط **"📥 تحميل"**
- ستحصل على ملف JSON أو CSV
